# Full Disclosure Verdict

**Autonomous agent-powered litigation support** for record screening, chronology building, and pre-expert analysis.

## What the agent does
- Ingests case files (PDFs, records, notes)
- Builds source-linked chronologies
- Flags gaps, contradictions, and missing documents
- Preserves every source reference (document + page)
- Delivers clean handoff packages for attorneys

## How it works
Multi-step autonomous reasoning with **human oversight** at every key step.  
Powered by my VS Code + terminal infrastructure.
